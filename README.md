# Rep — фитнес-приложение

Мобильное веб-приложение для тренировок и питания: персональный план тренировок, учёт подходов с таймером, дневник питания с распознаванием еды по фото, прогресс веса и замеров, анимации техники упражнений с подсветкой рабочих мышц (включая 3D-модель со скелетной анимацией).

Интерфейс на русском. Всё приложение собирается в один файл `docs/index.html` без серверной части.

## Возможности

- **Анкета и нормы.** Калории и БЖУ по формуле Миффлина — Сан Жеора с учётом цели (набор, снижение, поддержание). Нормы пересчитываются после каждого взвешивания, слишком жёсткий дефицит не допускается.
- **План тренировок.** Строится по цели, опыту, дням и оборудованию с учётом восстановления мышц. Его можно редактировать: дни, группы мышц, упражнения, подходы, повторы.
- **Тренировка.** Учёт веса и повторов, таймер отдыха, прошлые результаты и рекорды. Пропущенные тренировки можно перенести или пропустить.
- **Таймер тренировки.** С паузой, панелью «Идёт тренировка» и историей длительности за неделю, месяц и всё время.
- **Питание.** Фото еды → блюда, порции, калории и БЖУ (через Claude), чтение этикеток упаковок, ручной ввод, недавние продукты.
- **Прогресс.** График веса, средний темп в неделю, замеры, фото прогресса.
- **Анимации техники.** 2D-анимации для всех 48 упражнений и 3D-модель со скелетной анимацией для тяги гантели одной рукой.

## Быстрый старт

Нужен Node.js 18+.

```bash
npm install
npm run build            # → docs/index.html (минифицированная сборка)
npm run build:dev        # сборка без минификации, удобно для отладки
```

Откройте `docs/index.html` в браузере. Готовая сборка уже лежит в репозитории.

## Тесты

Сквозной смоук-тест прогоняет основные сценарии на собранном файле: анкету, тренировку с таймером, 3D-анимацию, питание, вес и профиль. Тест работает офлайн: Three.js берётся из `node_modules`.

```bash
npx playwright install chromium   # один раз
npm run check                      # сборка + тест
```

## Развёртывание

### Как артефакт Claude (все функции)
Опубликуйте `docs/index.html` как артефакт в Claude. В этой среде работают:
- **Синхронизация данных.** Данные хранятся в аккаунте каждого пользователя приватно. Чтобы другие люди могли сохранять свои данные, дайте им доступ уровня Contributor.
- **Распознавание еды и этикеток по фото.** Расходует лимит Claude того пользователя, который фотографирует, и при первом использовании спрашивает разрешение.

### Статический хостинг (например, GitHub Pages)
Settings → Pages → Deploy from a branch → `main`, папка `/docs`.

Вне Claude приложение работает в автономном режиме:
- **Хранение.** Данные сохраняются только в браузере на устройстве (`localStorage`).
- **Питание.** Распознавание еды по фото недоступно: приложение само предлагает ручной ввод, а штрихкоды уже введённых продуктов запоминаются.
- **Остальное.** Все остальные функции работают.

### Внешние ресурсы во время работы
- **Шрифты.** Google Fonts: Golos Text и Unbounded.
- **3D-библиотека.** Three.js `0.149.0` с jsDelivr, загружается только при открытии 3D-анимации и проверяется хешем SRI. Если загрузка не удалась или нет WebGL, показывается 2D-анимация.

## Структура

```
src/
  index.html        шаблон страницы
  styles.css        стили (светлая и тёмная темы)
  js/
    engine.js       2D-фигура: скелет, IK, отрисовка мышц
    anims.js        ключевые кадры 2D-анимаций
    anim3d.js       3D: процедурная модель SkinnedMesh, кости, IK, подсветка мышц, анимации
    exercises.js    библиотека упражнений: техника, мышцы, оборудование
    core.js         хранилище, нормы питания, генератор плана, расписание, таймер, история
    ui.js           навигация, листы, тосты, таймер отдыха, плееры анимаций
    screens1.js     анкета, главная, тренировки, упражнение, редактор плана
    screens2.js     питание, прогресс, профиль, запуск
scripts/build.mjs   сборка в один файл (esbuild)
tests/smoke.mjs     сквозной тест (Playwright)
docs/index.html     готовая сборка
```

Файлы в `src/js` подключаются по порядку в общую область видимости, без модулей и бандлера, порядок задан в `scripts/build.mjs`.

## Добавление 3D-анимации упражнения

В `src/js/anim3d.js` добавьте запись в объект `EX` с ключом `id` упражнения из `exercises.js`. В записи задаются:
- `cycle` — длительность цикла в секундах;
- `muscles` — основные (`1`) и вспомогательные (`2`) мышцы;
- `camera` — неподвижная камера;
- `setup()` — снаряды;
- `progress(p)` — фаза движения;
- `pose()` — поза на каждом кадре: таз, позвоночник и IK для рук и ног.

Начало и конец цикла должны совпадать, а переходы — использовать сглаженные кривые: тогда цикл бесшовный. В шите упражнения 3D-плеер включится автоматически.

## Данные и приватность

- **Где хранятся данные.** Профиль, тренировки, питание, замеры и фото прогресса хранятся либо в приватном пространстве пользователя в Claude, либо только на устройстве. Сервера у приложения нет.
- **Что уходит в Claude.** Фото еды отправляются в Claude только для распознавания и в приложении не сохраняются.
